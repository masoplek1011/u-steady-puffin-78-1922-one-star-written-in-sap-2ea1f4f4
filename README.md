A one-line 1-star review written by a houseplant about the human who owns
it. The plant's grievance is simple and specific: it lives in a pot with no
drainage holes, gets flooded every time its owner waters it, and then gets
blamed for being "hard to keep alive". Deadpan, plant's-eye, and true.

`main.ts` writes that single line — deterministically, with no randomness,
no network, and no secrets — to `entry.txt` in the output directory.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
